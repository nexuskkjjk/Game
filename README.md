# 🚀 Como Rodar o Jogo no seu PC

Este é um jogo construído com **React** e **Vite**. Ele roda no seu navegador, mas você pode executá-lo localmente como se fosse um programa.

## 📋 Pré-requisitos

Você precisará do **Node.js** instalado no seu computador.
- Baixe aqui: [https://nodejs.org/](https://nodejs.org/) (Recomendamos a versão LTS).

## 🛠️ Passo a Passo para Executar

1. **Baixe o Código:**
   - No menu do AI Studio, vá em **Settings** > **Export to ZIP**.
   - Extraia o arquivo ZIP em uma pasta no seu computador.

2. **Abra o Terminal:**
   - No Windows: Abra o `Prompt de Comando` ou `PowerShell` dentro da pasta do jogo.
   - No Mac/Linux: Abra o `Terminal` na pasta do jogo.

3. **Instale as dependências:**
   Digite o comando abaixo e aperte Enter:
   ```bash
   npm install
   ```

4. **Inicie o Jogo:**
   Digite o comando abaixo e aperte Enter:
   ```bash
   npm run dev
   ```

5. **Acesse no Navegador:**
   O terminal mostrará um link (geralmente `http://localhost:3000`). Clique nele ou copie e cole no seu navegador.

---

## 💡 Por que não é em Python?
Python é excelente para dados e inteligência artificial, mas para criar interfaces visuais modernas, fluidas e com animações complexas (como as deste jogo), o **React (Web)** é a ferramenta padrão da indústria. Usar React garante que o jogo funcione em qualquer lugar sem erros de compatibilidade gráfica.

**Divirta-se programando!** 🎮
